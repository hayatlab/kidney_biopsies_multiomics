## Xenium_Design_Files

The `Xenium_Design_Files/` folder contains all final outputs from the Xenium designer from 10X Genomics, including:

- `GT3ZEN_hKidney_468g_web_summary.html`
- `GT3ZEN_hKidney_468g_gene_list.csv`
- `GT3ZEN_hKidney_468g_panel.json`
- `GT3ZEN_hKidney_468g_probe_info.csv.gz`
- `GT3ZEN_hKidney_468g_probes.bed`
